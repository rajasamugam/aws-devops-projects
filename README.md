## 🏆 Key Projects

### 1. AWS CloudWatch Auto-Stop EC2 Project
> Automatically stops an EC2 instance when CPU utilization drops below 30% using CloudWatch alarms, SNS notifications, and IAM roles — demonstrating real-world cost optimization.
> **Services:** EC2 · CloudWatch · SNS · IAM

### 2. VPC Setup with Subnets & Security Groups
> Designed and deployed a custom AWS VPC with public/private subnets across multiple Availability Zones with Internet Gateway, NAT Gateway, and Security Groups.
> **Services:** VPC · Subnets · IGW · NAT Gateway · Route Tables · Security Groups

### 3. EFS Shared Storage Across Multiple AZs
> Configured Amazon EFS and mounted it across multiple EC2 instances in different Availability Zones enabling shared persistent storage.
> **Services:** EFS · EC2 · IAM · Multiple AZs

### 4. Load Balancer & Auto Scaling Setup
> Deployed Application Load Balancer with Auto Scaling Groups to automatically scale EC2 based on traffic demand.
> **Services:** ALB · Target Groups · Auto Scaling · EC2 · CloudWatch

### 5. CI/CD Pipeline with Jenkins *(In Progress)*
> End-to-end CI/CD pipeline using Jenkins integrated with GitHub for continuous delivery.
> **Services:** Jenkins · GitHub · CI/CD · Linux · Shell Scripting

### 6. Terraform Infrastructure Deployment *(In Progress)*
> Terraform IaC configuration to provision AWS infrastructure including EC2, VPC, Security Groups, and S3.
> **Services:** Terraform · EC2 · VPC · S3 · IaC
